Statistics and Probability in Python

Overview
This project demonstrates core concepts of Statistics and Probability with practical Python implementations. 
It combines theory, worked examples, and simulations in Python (Google Colab + scripts). 
The project covers probability of events, conditional probability, independence of events, and random variables.

Topics Covered
1. Probability of Events
   - Events, sample space, and probability rules
   - Theoretical, experimental, and conditional probability
   - Real-world examples (cards, dice)

2. Conditional Probability
   - Independent vs dependent events
   - Calculation of conditional probability
   - Python simulation of dice rolls with conditions

3. Independence of Events
   - Definition and examples
   - Python implementation verifying independence vs dependence

4. Random Variables
   - Discrete vs continuous random variables
   - Expected value and variance
   - PMF visualization of a die roll using Python
   - Real-world applications (finance, insurance, weather, gaming)

Python Code Highlights
- Simulation of dice rolls
- Probability calculations
- Conditional probability estimation
- Independence testing
- PMF visualization with matplotlib

Tech Stack
- Language: Python
- Tools: Google Colab, Jupyter Notebook
- Libraries: numpy, matplotlib
